# Builder Swarm Agent Workflow

```text
Competition Brief
  ↓
Idea Validator Agent
  ↓
Market Research Agent
  ↓
MVP Scope Agent
  ↓
Project Manager Agent
  ↓
Builder/Coder Agent
  ↓
Pitch Agent
  ↓
Open Source + Evidence Agent
  ↓
Competition Launch Packet
```

## Agent Roles

### 1. Idea Validator Agent
Pressure-tests the idea, identifies weak assumptions, and recommends a sharper MVP.

### 2. Market Research Agent
Checks competitors, substitutes, community language, and differentiation.

### 3. MVP Scope Agent
Defines what must be built now, what should wait, and what should be cut.

### 4. Project Manager Agent
Turns scope into milestones, tasks, risks, blockers, and definition of done.

### 5. Builder/Coder Agent
Creates repo structure, prototype scaffolding, and implementation notes.

### 6. Pitch Agent
Writes the project narrative, README language, demo script, and submission copy.

### 7. Open Source + Evidence Agent
Creates the AI usage log, contribution guide, license checklist, and proof packet.
