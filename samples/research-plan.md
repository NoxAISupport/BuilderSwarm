# Research Plan

## Questions to Verify
1. What project-planning tools already serve hackathons or competitions?
2. What AI coding/planning tools look similar, and how is Builder Swarm different?
3. Which open-source agent workflow examples can we learn from?
4. What artifacts do competition judges typically need?
5. What makes the first 48 hours of a project difficult for builders?

## Differentiation Hypothesis
Builder Swarm is not a generic chatbot or PM board. It is competition-specific:
- reads rules and deadlines
- cuts MVP scope based on time
- maps work to judging criteria
- generates submission assets
- documents AI usage
- creates open-source-ready repo artifacts

## Evidence to Capture
- Competitor list and differentiators.
- Screenshots of Builder Swarm output.
- AI usage log.
- Example before/after: rough idea → launch packet.
- 2–3 community/builder reactions if Ian approves outreach.
