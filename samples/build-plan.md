# Build Plan

## Now
- Build static demo console.
- Add sample SSTB project input.
- Add agent cards and timeline.
- Add artifact tabs.
- Add copy/download controls.
- Upload review copies to Google Drive.

## Next
- Add generated output bundle under `/outputs`.
- Improve README and demo script.
- Add architecture documentation.
- Add contribution guide and license.
- Run a fresh-clone style smoke test.

## Later
- Add optional live AI backend.
- Add ZIP export.
- Add competition template gallery.
- Add community-submitted agent templates.

## Risks
- If it looks like a static template, agentic value may seem weak.
- If it tries to become a full agent platform, scope will explode.
- If sample outputs are generic, judges will not care.

## Definition of Done for MVP
- Local demo runs without a build step.
- Sample input and outputs are included.
- README explains what it is, why it is agentic, and how to run it.
- Demo script and submission checklist exist.
