**Builder Swarm** — I built an AI competition cofounder for SSTB… and used it to plan itself 🌀

**What it does:**
Paste any competition brief → specialized agents scope the project, research the domain, scaffold the repo, draft the README, write the demo script, and generate a submission checklist.

**What you're looking at:**
- 📋 **Competition Analyst** agent parses the rules
- 🔍 **Research Scout** finds relevant tools/papers
- 📐 **Scope Planner** breaks it into tasks
- 💻 **Coder agent** scaffolds the repo
- ✅ **QA + Demo Writer** finish the package

**I used it on the SSTB brief.** It scoped Builder Swarm itself. Recursion is underrated.
