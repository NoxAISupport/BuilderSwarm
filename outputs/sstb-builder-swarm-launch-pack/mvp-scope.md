# MVP Scope

## Must Have
- Competition brief input form.
- Visible swarm of named agents.
- Sequential workflow timeline.
- Generated Markdown artifacts:
  - project brief
  - MVP scope
  - research plan
  - build plan
  - repo scaffold
  - demo script
  - AI usage log
  - submission checklist
- Copy/download artifact buttons.
- Sample SSTB run showing Builder Swarm planning itself.

## Nice Later
- Live LLM API calls.
- ZIP export.
- GitHub issue generation.
- Team collaboration.
- Competition template gallery.
- Hosted public demo.

## Cut Now
- Accounts/auth.
- Database.
- Payments.
- Deep integrations.
- Fully autonomous coding.
- General-purpose project management dashboard.

## Success Criteria
A judge can understand the idea in under 60 seconds and see the agentic workflow create a useful competition launch packet in under 2 minutes.
