# Demo Script

## 0:00 — Problem
"Builders often have a good competition idea, but lose time turning rules and constraints into a realistic build plan."

## 0:20 — Input
Show the SSTB competition brief, deadline, rules, and the rough Builder Swarm idea.

## 0:45 — Swarm Workflow
Click **Run Builder Swarm**. Show the named agents moving through the workflow: Rule Parser, Idea Validator, Market Researcher, Project Manager, Builder Agent, and Submission Coach.

## 1:15 — Outputs
Open the generated artifacts: project brief, MVP scope, build plan, repo scaffold, demo script, and checklist.

## 1:45 — Why Agentic
"This is not a single response. The workflow decomposes the launch process into specialist roles, each producing an artifact that feeds the final competition packet."

## 2:10 — Open Source / Community
Show the repo structure, contribution guide, and how community members can add competition templates or agent roles.

## 2:30 — Closing
"Builder Swarm helps future builders turn rough ideas into submitted projects faster. We used it to plan itself for this competition."
